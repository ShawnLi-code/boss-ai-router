# Boss AI Router

**BOSS直聘 AI测试岗位风控评估、动态简历匹配与多账号分流桌面应用（Tauri 2）**

基于本地浏览器 Profile 隔离（`ego-browser`）+ Tauri 2 桌面端 + Node.js 内置 SQLite，为不同简历口径的账号实现自动背调风险评分、A/B 轨分流、防撞车去重与半自动低风控投递。

</div>

---

## 核心特性

1. **双号隔离与分流路由（A/B 轨）**
   - **`A轨_真实日期版`**（高风控/央国企/银行金融/大厂驻场外包/严背调岗位）→ 路由至对应真实履历账号 Profile。
   - **`B轨_绿区池`**（低背调风险的民企/中小厂/技术直招岗位）→ 路由至对应绿区账号 Profile。
   - **`YELLOW 先探底后定轨`**：在可视化看板人工确认后再决定分流去向，支持一键对调账号绑定。

2. **量化风控模型 + 强制联网背调补查**
   - 满足 `规模 >= 100人` 或 `融资 >= A轮` 自动触发 `"{company_name}" (背调 OR 个税 OR 流水 OR 离职证明)` 联网检索并缓存至本地 SQLite。
   - 自动识别第三方背调机构（八方锦程、全景求是、i背调、太和鼎信、人人背调等）与核薪查个税/社保录屏等信号，并带有否定词（如“非外包”“不驻场”）及缩写词边界校验。

3. **动态简历匹配与定制 PDF 导出**
   - 支持直接从 Ego 浏览器同步读取各账号的 Boss 在线简历母版。
   - 不频繁修改原在线简历时间线；针对目标岗位 JD 计算匹配度、动态突出项目侧重点、生成 120 字以内专属打招呼话术，并支持导出定制版附件 PDF。

4. **低频拟人防封号 + 验证自动移交 + 同公司防撞车**
   - 单任务串行锁 + 随机拟人停顿（默认 `4.5s–8.5s`，强制 `>= 3s`）+ 每日各账号安全投递上限。
   - 遇到滑块、登录或安全验证时立即中止并调用 `task.handOff()`，桌面端顶部弹出醒目提示交出对应浏览器标签页。
   - **同公司硬去重防撞车**：同一公司已用 A 轨或 B 轨投递/预填后，拦截另一账号重复投递。

## 本地运行与桌面端构建

### 环境要求
- **Node.js** `>= 22.5`（使用内置 `node:sqlite`，已验证于 Node `v24.14.1`）
- **Rust & Cargo**（构建 Tauri 2 桌面端）
- **ego-browser**（Ego Lite CLI，用于多 Profile 隔离浏览与控制权移交）

### 安装依赖与运行

```bash
npm install
npm test
```

**方式 A：桌面端模式（Tauri 2）**

```bash
npm run desktop:dev
```

或编译发布版桌面端：

```bash
npm run desktop:build
```

**方式 B：Web 控制台模式**

```bash
npm start
# 浏览器打开 http://127.0.0.1:3789
```

## 隐私与安全边界
- 所有简历、岗位池、背调缓存、投递审计记录与可选大模型 API Key 仅存储在本地 SQLite 数据库（`data/` 目录或系统本地应用数据目录），不上传任何第三方平台后端。
- `.gitignore` 已默认排除 `data/`、`*.db`、`.env` 等所有运行时与凭据文件；向公开仓库提交代码前请勿提交个人简历或密钥。
